# Agentes especializados do Bom Conselho

Este diretório descreve os agentes de negócio/técnicos recomendados para evolução do produto.

## Como usar

1. Escolha um agente por objetivo de sprint.
2. Use `agents/registry.json` para identificar escopo e KPI.
3. Abra o arquivo de especificação do agente em `agents/especializados/`.
4. Converta as ações sugeridas em issues e tarefas no backlog.

## Agentes disponíveis

- `agente-ingestao-qualidade-dados`
- `agente-diagnostico-pedagogico`
- `agente-copiloto-documentos`
- `agente-governanca-lgpd`
- `agente-monetizacao-cs`
